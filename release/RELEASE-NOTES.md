# Job Scam Checker MVP 1.0.0

Production-ready WordPress plugin and theme packages for manual upload. This
release includes the private deterministic checker, editable default rules,
accessible risk results, 30 curated pages, native search, optional aggregate-only
statistics/trends, protected administration, metadata/schema, and hardened input,
output, REST, privacy, rate-limit, upgrade, and uninstall paths.

Requirements: WordPress 6.4+, PHP 7.4+ (PHP 8.2 recommended), and the normal
WordPress MySQL/MariaDB database. No paid service or external runtime dependency.

Install `job-scam-checker-1.0.0.zip` under Plugins, then
`job-scam-checker-theme-1.0.0.zip` under Themes. Follow
`docs/deployment-hostinger.md` in the source repository. Verify downloads against
`SHA256SUMS` before installation.

Important: the checker reports warning indicators, not proof of fraud or legal
advice. Review and localize Contact, Privacy Policy, Terms of Use, and Disclaimer
content before public launch. Anonymous statistics are disabled by default.
