# Privacy and security model

See [`phase7-hardening-performance.md`](phase7-hardening-performance.md) for the
current implementation audit. Checker text is processed locally in request
memory and is not permanently stored by this project. Optional statistics contain
only aggregated, allow-listed counters and are disabled by default.

Operators remain responsible for HTTPS, accounts and updates, hosting/security
logs, backups, incident response, and a privacy policy covering the complete site.
